# 第五章 质量控制体系与常见问题处理

> **本章提要**：本章构建苏木-CNE2-IC₅₀实验的五域质量控制（QC）红线体系，详细阐述每个关键实验节点的质控标准、预防措施与偏差处理程序。针对实验中最常见的8类问题提供根因分析（RCA）和CAPA（纠正与预防行动）方案，确保实验数据的可重复性与可信度。

---

## 5.1 五域质量控制红线体系概述

本实验建立以下五个质控域，每个域均设有明确的"绿区-黄区-红区"三级判定标准：

| 质控域 | 核心指标 | 检查频率 | 主要风险 |
|-------|---------|---------|--------|
| **域I** 细胞生物学质控 | 活力、形态、传代数、STR、支原体 | 每批次 | 细胞身份错误、污染 |
| **域II** 试剂与配制质控 | DMSO浓度、药物浓度精度、培养基灭活验证 | 每次配制 | 溶剂毒性、浓度偏差 |
| **域III** 96孔板操作质控 | CV值、边缘效应、移液精度 | 每块板 | 重复性差、边缘效应 |
| **域IV** CCK-8检测质控 | OD值范围、空白对照、显色均匀性 | 每次检测 | 信号超饱和、背景过高 |
| **域V** 数据分析质控 | R²、HillSlope、置信区间、批次间CV | 每次分析 | 拟合失败、假阳性结果 |

**质控红线原则**：
- **绿区**：继续实验，无需干预
- **黄区**：记录偏差，分析原因，可在监控下继续
- **红区**：立即停止本批次实验，启动偏差调查程序，不得出具本批次数据

## 5.2 域I：细胞生物学质量控制

### 5.2.1 CNE-2细胞核心质控参数

**每批次实验开始前，必须确认以下参数全部处于绿区方可开始铺板**：

| 参数 | 绿区（继续实验） | 黄区（监控并记录）| 红区（停止实验）|
|------|--------------|----------------|--------------|
| 台盼蓝活力 | ≥ 95% | 90%–94% | < 90% |
| 传代数 | P5–P20 | P4 或 P21–P25 | P1–P3 或 > P25 |
| 形态 | 典型多角形贴壁 | 少量圆形悬浮（≤5%）| 大量悬浮、颗粒增多 |
| 支原体检测 | 阴性（PCR法） | — | 阳性（立即废弃）|
| STR认证 | ≥ 80%匹配 | 75%–79%（复检）| < 75%（身份可疑）|
| 融合度（铺板前）| 70%–80% | 60%–69% 或 81%–90% | < 60% 或 > 90% |

**操作记录要求**：
每次实验须在细胞实验记录表中记录：
- 细胞复苏日期
- 当前传代次数（P？）
- 铺板前活力（台盼蓝法，人工计数）
- 最近一次支原体检测日期与结果
- 最近一次STR认证日期与认证机构

### 5.2.2 细胞状态异常的处理程序

**情形A：台盼蓝活力 < 90%（红区触发）**

根因分析步骤：
1. 检查CO₂培养箱温度（应为37.0 ± 0.5°C）和CO₂浓度（应为5.0 ± 0.2%）
2. 检查培养基是否变色（橙色→黄色提示酸化，粉红色提示碱化）
3. 检查传代操作：胰酶消化时间是否过长（>5 min可导致细胞损伤）
4. 检查培养瓶是否被意外污染（支原体可导致慢性活力下降）

纠正行动：
- 若为孵育条件问题：校准培养箱，更换培养基，观察恢复后再次计数
- 若为传代操作问题：调整胰酶用量和消化时间，重新传代
- 若怀疑支原体感染：立即进行PCR检测，结果阳性则整批细胞废弃，启用备份冻存管
- **本批次实验不得进行**，直至活力恢复至 ≥ 95%

**情形B：传代数超过P25（红区触发）**

CNE-2细胞高代次时会发生表型漂移，包括增殖速率改变、药物敏感性改变和基因组不稳定性增加。一旦发现传代数超出允许范围：

1. 立即从液氮中取出低代次（P5–P10）冻存备份，解冻并复苏
2. 将超代次细胞妥善废弃（高压蒸汽灭菌或10%次氯酸钠浸泡30 min后丢弃）
3. 记录超代次原因（是否为忘记记录、传代过频等）
4. 在新复苏细胞稳定（至少传2代，形态正常）后方可开始新一批实验

## 5.3 域II：试剂与药物配制质量控制

### 5.3.1 DMSO浓度合规性核查

**每次配制药物工作液前的DMSO合规计算必须有书面记录**：

**计算模板**（以最高浓度400 μg/mL为例）：

```
母液浓度：C_stock = 100 mg/mL = 100,000 μg/mL
最高工作液浓度：C_work = 400 μg/mL
稀释因子：F = C_work / C_stock = 400 / 100,000 = 1/250

取母液体积：V_stock = V_total / F = 1,000 μL / 250 = 4 μL
加培养基：V_medium = 1,000 - 4 = 996 μL
最高工作液中DMSO含量 = 4 μL × 100% / 1,000 μL = 0.40%

⚠️ 0.40% > 0.1%上限！

修正方案：工作液中用完全培养基1:10稀释：
取上述400 μg/mL工作液100 μL + 900 μL完全培养基 = 40 μg/mL，DMSO = 0.04%
实际加药：用40 μg/mL工作液直接加入孔中（100 μL/孔），孔内DMSO = 0.04% ✓
```

等效地，首选方案：
```
重新配制工作液：取母液4 μL + 完全培养基996 μL = 400 μg/mL工作液，DMSO = 0.40%
此工作液在96孔板中已是预稀释终浓度，不再做1:10稀释
孔中加入体积：直接取100 μL已预稀释的工作液加入孔中（孔内已含细胞100 μL）
孔内终浓度：400 μg/mL × 100 μL / 200 μL = 200 μg/mL，DMSO = 0.04% × 100/200 = 0.02% ✓

如需孔内终浓度为400 μg/mL，则工作液须配至800 μg/mL：
取母液8 μL + 992 μL培养基 = 800 μg/mL，DMSO = 0.08%
孔内：800 × 100/200 = 400 μg/mL，DMSO = 0.08% × 100/200 = 0.04% ✓
```

> ⚠️ **DMSO浓度红线**：若计算显示孔内终浓度DMSO > 0.1%，**必须调整配制方案**，不得以任何理由跳过此核查。

**DMSO溶剂对照组配制规范**：
- 溶剂对照组DMSO浓度**必须等于最高药物浓度组孔内的DMSO浓度**（本实验为0.04%）
- 配制方法：取4 μL DMSO + 996 μL完全培养基 = 1,000 μL，浓度0.40%
- 加入孔内：100 μL此溶液 + 100 μL细胞悬液（已在孔内）= 200 μL，孔内DMSO = 0.02%
- **或**若孔内已预先加好细胞100 μL，则直接加入100 μL溶剂对照液（0.04% DMSO），孔内终浓度 = 0.02%

### 5.3.2 药物配制的天平和移液精度核查

| 配制步骤 | 允差标准 | 核查方法 |
|---------|--------|--------|
| 苏木提取物称量（≥10 mg）| ±0.5 mg（即≤5%相对误差）| 万分之一天平，两次称量取均值 |
| DMSO（母液配制）| ±0.2 μL（≤2%，对≥10 μL操作）| 采用10 μL或100 μL微量注射器 |
| 小体积移液（<10 μL）| ±0.2 μL | 使用0.5–10 μL量程移液器，称重法验证 |
| 多道移液器（96孔板加药）| ±5%（OD值CV验证）| 各列间OD CV ≤ 5% |

**移液器定期校准要求**：
- 单道移液器：每6个月校准一次（水重量法，10次重复）
- 多道移液器：每3个月校准一次（同上）
- 校准记录须存入仪器档案

## 5.4 域III：96孔板操作质量控制

### 5.4.1 边缘效应监控

**边缘效应（Edge Effect）**是指96孔板最外圈孔（A行、H行、第1列、第12列，共36个孔）因蒸发率高于内圈孔，导致培养液浓度升高，细胞生长与内圈孔存在系统性差异的现象。本实验通过PBS封边（参见第三章3.1.2节）从根本上消除边缘效应。

**边缘效应后验核查方法（每批次完成后）**：

在分析数据时，比较同一浓度组中靠近板边缘的孔（如B2, B11, G2, G11，即内圈角落孔）与中央孔的OD值差异：

$$\text{边缘-中央偏差} = \frac{|OD_{角落孔} - OD_{中央孔均值}|}{OD_{中央孔均值}} \times 100\%$$

- **< 5%**：绿区，PBS封边效果良好
- **5%–10%**：黄区，记录偏差，评估是否影响IC₅₀结果
- **> 10%**：红区，提示PBS封边失效（可能为加液不足或培养期间蒸发），该批次数据需重新评估

---

### 5.4.2 移液重复性（Pipetting CV）核查

**最简快速验证方法（推荐在正式实验前进行）**：

1. 配制一份统一的CCK-8稀释液（1:10，完全培养基稀释）
2. 向一块空96孔板的内圈60个孔（B2–G11）各加入100 μL该稀释液
3. 使用酶标仪在450 nm读取所有孔的OD值
4. 计算全部60个孔的均值和SD，计算CV

| 结果 | 判断 | 处置 |
|------|------|------|
| CV ≤ 3% | 优秀 | 可开始正式实验 |
| CV 3%–5% | 合格 | 可开始实验，注意操作一致性 |
| CV 5%–8% | 勉强 | 检查移液器是否需要校准或维修 |
| CV > 8% | 不合格 | 查找移液不一致根因（见5.6节） |

## 5.5 域IV：CCK-8检测质量控制

### 5.5.1 CCK-8试剂质量核查

**每批次使用前，从-20°C取出CCK-8试剂时须核查**：

| 检查项目 | 合格标准 | 问题处理 |
|---------|--------|--------|
| 外观 | 澄清橙红色溶液，无沉淀 | 若出现沉淀，置于37°C水浴10 min复溶 |
| 有效期 | 距生产日期<24个月 | 过期试剂废弃，不得使用 |
| 分装小管编号 | 记录批次号（Lot No.）| 全程使用同一批次，不混用 |
| 避光包装完整性 | 铝箔包装完整 | 若有漏光，检查试剂颜色是否异常 |

**CCK-8"热身"操作要点**（参见第三章3.3.1节的详细步骤）：
- 从-20°C取出后必须在**室温（20–25°C）下平衡30 min**，不得直接加入4°C或37°C试剂
- 严禁反复冻融，建议每管分装100–200 μL（单次使用量），用后立即冻存

### 5.5.2 OD值异常的判断与处置

**异常情形A：空白孔OD值异常偏高（> 0.200）**

可能原因：
1. 空白孔意外落入细胞（铺板操作不仔细）
2. 空白孔加入了CCK-8后出现非细胞来源的显色（试剂本底过高）
3. 苏木提取物色泽干扰（未设置药物空白孔）
4. 酶标仪光路污染（比色皿或滤光片被污染）

处理步骤：
1. 检查图像记录中空白孔的细胞形态（是否有细胞）
2. 若确认空白孔内有细胞，该空白孔数据弃用，用其余空白孔均值替代
3. 若空白孔OD整体偏高（全部5个孔均> 0.150），需重新评估背景来源
4. 联系仪器管理员检查酶标仪光路

**异常情形B：溶剂对照组OD值过低（< 0.300）**

判断阈值：溶剂对照（正常生长细胞）OD均值 < 0.300（背景扣除后）

可能原因：
1. 细胞铺板密度不足或铺板前活力过低
2. 加药时（Day 2）遗漏了某些孔（空加完全培养基而非细胞悬液）
3. 孵育时间不足（从铺板到CCK-8检测时间<24h）
4. CCK-8孵育时间不足（< 60 min）

处理步骤：
1. 核对铺板记录，确认溶剂对照孔是否有细胞
2. 若为铺板问题，本时间点数据不可用，需补做实验
3. 若为CCK-8孵育时间不足，可继续孵育至OD值在合理范围，但须记录实际孵育时长

**异常情形C：药物浓度组OD值高于溶剂对照（细胞活力>100%）**

发生时机：低药物浓度组（如0.004 μg/mL）出现OD值 > 溶剂对照组均值

可能原因：
1. 统计学波动（正常的随机误差，偶发）
2. 苏木提取物在极低浓度下存在促增殖效应（Hormesis效应，文献中已有报道）
3. 移液误差

处理策略：
- 若细胞活力 > 100%但 < 110%：记录此现象，正常纳入数据，抑制率计算为负值（如 -8.3%），表示轻微促增殖效应，可报告但不影响IC₅₀计算
- 若细胞活力 > 120%：可能为实验误差，触发Grubbs检验
- 在方法学讨论中说明此低浓度Hormesis现象及其可能机制

## 5.6 域V：数据分析质量控制

### 5.6.1 高CV的8类根本原因分析

**背景**：实验中最常见的质控问题是某浓度组重复孔CV > 10%，甚至> 15%。以下8类根因涵盖了>90%的高CV案例：

| 根因编号 | 根因描述 | 识别方法 | 预防/纠正措施 |
|---------|---------|--------|------------|
| **R01** | 移液器系统误差（活塞磨损、量程过小）| 离群值出现在特定通道位置（如D道偏低）| 校准/更换移液器，使用容量接近量程的更大规格枪 |
| **R02** | 加CCK-8时操作速度不一致导致部分孔提前显色 | 孔间时序差>5 min | 使用多道移液器一行一行添加，控制操作时间 |
| **R03** | 气泡导致OD假低值 | 检查原始孔图像（若酶标仪支持孔扫描）| 读板前目视检查，挑破气泡 |
| **R04** | 加药量误差（移液器针头残留）| 某浓度组两侧孔高、中间孔低（或相反）| 每换一个浓度更换枪头，避免携带残留 |
| **R05** | 边缘效应（PBS封边失效）| 板角孔与中央孔OD差>10%，以及角落孔的异常高值 | 确认所有36个外圈孔均已加200 μL PBS |
| **R06** | 细胞不均匀沉降（铺板后移动了96孔板）| 某几行/列细胞密度偏高 | 铺板后水平轻摇混匀，不要来回转动，放入培养箱后不得移动 |
| **R07** | DMSO在高浓度端对细胞的额外毒性叠加 | 高浓度组CV高，低浓度组CV正常 | 核算DMSO终浓度，若>0.1%则重新配制药物工作液 |
| **R08** | 培养箱内温度不均匀（孔位系统性偏差）| 同一列内OD从上到下呈梯度 | 将96孔板放置在培养箱中央，定期校准培养箱温度 |

### 5.6.2 S形曲线拟合失败的处理

**情形A：R² < 0.95，曲线呈非典型形状**

当GraphPad Prism拟合结果显示R² < 0.95时，按以下流程排查：

```
Step 1: 查看残差图（Residuals plot）
  ├─ 残差随机分布 → 数据本身质量好，可能是模型选择问题
  │   → 尝试两参数模型（HillSlope=1固定）或三参数模型（Bottom不固定）
  └─ 残差有系统模式（U形或连续同向）→ 数据存在系统误差
      → 进入Step 2

Step 2: 检查浓度范围
  ├─ 最低浓度抑制率 > 20%：浓度范围偏高，最低浓度应继续降低
  └─ 最高浓度抑制率 < 80%：浓度范围偏低，最高浓度应提高

Step 3: 检查高浓度端
  ├─ 最高浓度抑制率明显低于次高浓度（曲线"回钩"）
  │   → 提示高浓度溶剂（DMSO）毒性效应叠加
  │   → 解决：核算DMSO浓度，重新配制；或将最高浓度点剔除
  └─ 高浓度端曲线平台未达100%
      → 考虑苏木对CNE-2的部分抑制特性（partial agonist/partial inhibitor）
      → 放开Top参数约束，允许Prism自由拟合Top值

Step 4: 补充实验
  → 增加1–2个浓度梯度点，覆盖未被充分采样的抑制率区间（20%–80%）
```

**情形B：IC₅₀置信区间过宽（> 5倍IC₅₀值）**

原因：单时间点或单批次的重复数不足（< 3次独立重复）

解决：累积3次或以上独立生物学重复（不同批次细胞，不同批次药物），用3次IC₅₀均值±SD报告

---

### 5.6.3 批次间重复性核查

**3次独立重复实验（n=3）的批次间变异核查标准**：

| 批次间CV | 质控判断 | 处置 |
|---------|--------|------|
| ≤ 10% | 绿区，重复性优良 | 按计划报告 |
| 10%–20% | 黄区，重复性一般 | 分析原因，必要时增加第4次重复以提高统计把握度 |
| > 20% | 红区，批次间差异过大 | 排查批次差异来源（见下），不得以3次结果直接计算均值 |

**批次间差异过大的常见原因（> 20% CV）**：

1. **细胞代次不同**：不同批次使用了P8和P18的细胞，高代次细胞药物敏感性可能改变
   - 解决：严格限制同一实验项目使用P5–P15的细胞，减小代次窗口

2. **药物批次不同**：不同批次提取的苏木提取物纯度/成分比例存在批次差异
   - 解决：本研究所有实验使用同一批提取物（同批次，同编号，-20°C分装冻存），记录药物批次号于每次实验记录中

3. **FBS批次不同**：FBS批间差异较大，会影响细胞基础增殖率
   - 解决：全程使用同一批次FBS（购买时批量订购并进行批次验证，记录批号），并进行FBS批次筛选（增殖曲线验证）

4. **季节性或时段性影响**：夏季培养箱开门频繁导致温度波动
   - 解决：在固定时间段（如上午9–11点）操作，避免高峰使用期

## 5.8 生物安全与废弃物处置规范

### 5.8.1 CNE-2细胞的生物安全等级

CNE-2细胞为人源鼻咽癌来源的BSL-2级生物材料，需按以下要求操作：

| 防护要求 | 规范 |
|---------|------|
| 个人防护装备（PPE）| 实验室外套 + 乳胶手套（双层）+ 口罩（≥ N95）+ 护目镜 |
| 操作区域 | 生物安全柜（BSC II型A2或B2级）内操作，禁止在开放台面操作 |
| 气溶胶防护 | 离心操作须在密封离心管内进行，离心机设有防气溶胶盖 |
| 锐器 | 所有针头直接投入硬质锐器收集桶，禁止回套 |

### 5.8.2 含细胞废液的灭活处置流程

**每次实验结束，按以下步骤处置含细胞废弃物**：

1. 将96孔板中的废弃培养基（含细胞残余）倒入废液桶（已预装10%次氯酸钠溶液）
2. **浸泡时间 ≥ 30 min**，确保充分灭活
3. 96孔板（含细胞）置于黄色医疗废物袋中，集中进行**高压蒸汽灭菌（121°C，30 min）**
4. 灭活后的废液经过检测（pH < 7，次氯酸钠失效则需重新处理）后，按废水规定排放
5. 废物袋及固体废弃物由专业机构集中收集处理

**残余苏木提取物的处置**：
- 实验剩余的苏木提取物工作液（已与培养基混合）可直接加入次氯酸钠废液桶灭活
- 苏木提取物DMSO母液（未与细胞接触）：转移至化学废液收集容器，标注含DMSO，由实验室专职人员统一处置

```

□ 铺板密度：8,000细胞/孔（100 μL/孔）

```

### 加药后（Day 2）核查项

```
□ 空白对照孔已标注（仅含培养基，无细胞，无药）
```
