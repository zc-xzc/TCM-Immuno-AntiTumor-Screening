### 4.1.3 OD值可信区间核查

在进行离群值检验前，首先对每组OD值进行基础可信核查：

**第一步：检查空白对照组OD值范围**

```
空白孔OD值（空白校正前）理论范围：0.050–0.150
若空白孔OD < 0.050：提示CCK-8试剂失效或加量不足
若空白孔OD > 0.200：提示可能存在荧光干扰或孔内有残留细胞
```

**第二步：检查溶剂对照组OD值范围**

```
溶剂对照组（正常生长细胞）OD值理论范围：0.400–1.200
若OD < 0.300：细胞活力不足，本批次实验结果需重新评估
若OD > 1.500：细胞过多或孵育时间过长，导致信号饱和
```

**第三步：计算组内变异系数（CV）初步筛查**

$$CV(\%) = \frac{标准差(SD)}{算术平均值(Mean)} \times 100\%$$

- **CV ≤ 10%**：孔内重复性优良，全部孔位数据有效
- **10% < CV ≤ 15%**：孔内重复性一般，触发Grubbs离群值检验
- **CV > 15%**：孔内变异过大，无论离群值检验结果如何，本组数据须标记为"不可信"，需重新补充实验

---

### 4.1.4 Grubbs离群值检验（G检验）

**适用场景**：某组重复孔CV > 10%，需判断是否存在统计意义上的离群点。

**Grubbs检验统计量（G值）计算公式**：

$$G = \frac{|x_i - \bar{x}|}{s}$$

其中：
- $x_i$：被检验的可疑值
- $\bar{x}$：所有测定值的算术平均数
- $s$：所有测定值的标准差

**操作步骤（Excel手动计算示例）**：

> 示例情景：400 μg/mL组5个重复孔OD值为：0.210, 0.215, 0.212, 0.218, 0.185

**步骤1**：计算均值

$$\bar{x} = \frac{0.210 + 0.215 + 0.212 + 0.218 + 0.185}{5} = 0.208$$

**步骤2**：计算标准差

$$s = \sqrt{\frac{\sum(x_i - \bar{x})^2}{n-1}} = \sqrt{\frac{(0.002)^2 + (0.007)^2 + (0.004)^2 + (0.010)^2 + (-0.023)^2}{4}} = 0.0136$$

**步骤3**：对可疑最小值0.185计算G值

$$G_{计算} = \frac{|0.185 - 0.208|}{0.0136} = \frac{0.023}{0.0136} = 1.69$$

**步骤4**：查阅Grubbs检验临界值表（α = 0.05，n = 5）

$$G_{临界}(n=5, \alpha=0.05) = 1.672$$

**步骤5**：判断

$$G_{计算}(1.69) > G_{临界}(1.672) \Rightarrow \text{0.185为离群值，予以剔除}$$

**剔除后重新计算**：

剩余4个值：0.210, 0.215, 0.212, 0.218 → 均值 = 0.21375，SD = 0.00340，CV = 1.59%（优良）

**Grubbs检验临界值表（常用n值，α = 0.05）**：

| 重复孔数(n) | G临界值(α=0.05) | G临界值(α=0.01) |
|------------|----------------|----------------|
| 3 | 1.155 | 1.155 |
| 4 | 1.481 | 1.496 |
| 5 | 1.715 | 1.764 |
| 6 | 1.887 | 1.973 |
| 7 | 2.020 | 2.139 |
| 8 | 2.126 | 2.274 |

> ⚠️ **注意**：每组数据**仅允许进行一次Grubbs检验**，不得连续剔除多个值以"拉高"统计达标率。若剔除一个值后剩余数据仍CV > 15%，视为本组实验数据不可用，须重新实验。

### 4.1.5 苏木提取物色泽干扰的背景扣除

苏木乙醇提取物呈深红棕色，其色泽本身可对OD₄₅₀有贡献，影响CCK-8比色结果。需设置"**药物空白孔**"（Drug Blank Wells）进行背景扣除。

**药物空白孔定义**：含相同浓度药物 + CCK-8，但**不含细胞**的对照孔。

**背景扣除公式**：

$$OD_{校正} = OD_{含细胞孔} - OD_{药物空白孔}$$

**Excel中批量背景扣除操作**：

1. 在工作表2中建立"背景扣除"计算区域
2. 对应每个药物浓度，设置独立药物空白列：`=药物孔OD - 对应浓度药物空白孔OD均值`
3. 后续所有计算均使用背景扣除后的OD校正值（OD_校正）

> 若未预设药物空白孔，可采用以下补救方法：将含同等浓度苏木提取物（不含细胞，不含CCK-8）的孔在加CCK-8并孵育后读取OD值，作为后补背景值。

## 4.2 细胞活力与抑制率计算

### 4.2.1 细胞活力（Cell Viability）计算

**公式**：

$$\text{细胞活力}(\%) = \frac{\overline{OD_{药物组}} - \overline{OD_{空白组}}}{\overline{OD_{溶剂对照组}} - \overline{OD_{空白组}}} \times 100\%$$

其中：
- $\overline{OD_{药物组}}$：某浓度药物组各重复孔OD校正值的均值（离群值已剔除）
- $\overline{OD_{空白组}}$：空白对照组（无细胞）各重复孔OD校正值的均值
- $\overline{OD_{溶剂对照组}}$：溶剂对照组（0.04% DMSO + 细胞，无药物）各重复孔OD校正值的均值

**计算示例（24 h时间点）**：

已知各组平均OD值（背景扣除后）：
- 空白组均值：0.082
- 溶剂对照组均值：0.756
- 400 μg/mL药物组均值：0.162

$$\text{细胞活力}_{400\mu g/mL} = \frac{0.162 - 0.082}{0.756 - 0.082} \times 100\% = \frac{0.080}{0.674} \times 100\% = 11.87\%$$

---

### 4.2.2 增殖抑制率（Inhibition Rate）计算

**公式**：

$$\text{抑制率}(\%) = 100\% - \text{细胞活力}(\%)$$

**承接上例**：

$$\text{抑制率}_{400\mu g/mL, 24h} = 100\% - 11.87\% = 88.13\%$$

---

## 4.3 GraphPad Prism 9.0 IC₅₀计算全流程操作教程

> **软件版本要求**：GraphPad Prism 9.0 或更高版本（Windows/macOS均适用）
> **预计操作时间**：熟练操作者约15–20分钟/时间点，初次操作约45–60分钟

---

### 4.3.1 第一步：创建新项目文件

**操作路径**：

1. 打开 GraphPad Prism 9.0，弹出欢迎界面（Welcome to Prism）
2. 在左侧 **New Project** 区域，点击 **"XY Graph"**（X-Y图表类型）
3. 在右侧 **Data Table** 设置区域：
   - **X axis**：选择 **"Numbers"**（数字类型）
   - **Y axis replicate values**：选择 **"Enter and plot a mean with SD"**（输入均值与SD）
4. 点击右下角 **"Create"** 按钮，进入数据表格界面

> ℹ️ **为何选XY Graph？**：IC₅₀的剂量-反应曲线是典型的X（药物浓度对数值）对Y（抑制率或活力百分比）散点连线图，Prism的XY图类型与内置的非线性回归模型完全适配。

---

### 4.3.2 第二步：数据输入

**数据格式要求**：

在数据表格界面，需输入两种类型的数据：
- **X列**：各药物浓度值（μg/mL），此列无需取log，后续模型中设定
- **Y列（A列）**：对应浓度的**抑制率（%）**均值（Mean）
- **Y列（B列）**：对应浓度的SD值

**具体输入步骤**：

1. 确认 **X column** 标题行显示为 "X"，若不是，点击标题行重命名
2. 在 **Group A** 列标题处右键 → **"Format Column"** → 选择 **"Mean and SD"**（均值和标准差）
3. 将列名从 "A" 重命名为 **"Sappan Wood Extract"**（点击标题行 → 直接输入）

**数据录入表格（以24h时间点为例）**：

在Prism数据表格中逐行输入以下数据：

| X（浓度, μg/mL） | Mean（抑制率, %） | SD |
|----------------|-----------------|-----|
| 0.004 | 6.7 | 1.8 |
| 0.04 | 17.5 | 2.1 |
| 0.4 | 35.2 | 3.4 |
| 4 | 56.0 | 2.8 |
| 40 | 75.4 | 3.1 |
| 400 | 88.1 | 2.5 |

**输入注意事项**：
- X列**输入原始浓度值**（0.004, 0.04, 0.4, 4, 40, 400），不要输入log值
- Y列输入**抑制率百分比数值**（6.7, 17.5...），不输入"%"符号
- 若某浓度组有离群值被剔除，均值和SD用实际保留孔数计算的值重新计算后填入

> ⚠️ **关键提醒**：确认X列数值已正确输入，尤其注意小数点（0.004 vs 0.04 vs 0.4），错误的浓度值将导致IC₅₀计算错误。建议输入完毕后，将Prism中的X列数值与Excel计算表中的浓度列逐一核对。

---

### 4.3.3 第三步：非线性回归分析设置

**操作路径**：

1. 在顶部菜单栏点击 **"Analyze"**（分析）
2. 弹出分析对话框，在左侧 **"XY analyses"** 列表中选择 **"Nonlinear regression (curve fit)"**（非线性回归/曲线拟合）
3. 点击 **"OK"** 进入回归模型选择对话框

**模型选择操作**（关键步骤）：

4. 在模型选择对话框中，展开左侧树状列表 **"Dose-Response - Inhibition"**（剂量-反应-抑制）
5. 选择 **"log(inhibitor) vs. normalized response -- Variable slope"**（对数抑制剂浓度 vs. 标准化反应 — 可变斜率）

> ℹ️ **模型解读**：此模型即**四参数Logistic模型（4PL）**，数学表达式为：
> $$Y = Bottom + \frac{Top - Bottom}{1 + 10^{(LogIC_{50} - X) \times HillSlope}}$$
> 其中：Top = 曲线上渐近线（理论最大抑制率），Bottom = 曲线下渐近线（理论最小抑制率），LogIC₅₀ = IC₅₀的对数值，HillSlope = 曲线坡度（Hill系数）

**参数约束设置**（Constraints）：

6. 在右侧点击 **"Constrain"** 标签页（约束参数）
7. 将 **"Top"** 参数约束为 **"100"**：
   - 点击 Top 行的 "Rules" 下拉框 → 选择 **"Constant equal to"**
   - 在数值框中输入 **100**
8. 将 **"Bottom"** 参数约束为 **"0"**：
   - 点击 Bottom 行的 "Rules" 下拉框 → 选择 **"Constant equal to"**
   - 在数值框中输入 **0**

> ℹ️ **为何约束Top=100，Bottom=0？**：将Top约束为100%（最大抑制率），Bottom约束为0%（基础增殖水平），使IC₅₀的计算基于归一化的抑制率量表，确保不同批次、不同时间点的IC₅₀数值具有可比性，符合NMPA《抗肿瘤药物药效研究技术指导原则》的标准化要求。

**X轴对数变换设置**：

9. 在同一对话框中点击 **"X"** 标签页（X轴设置）
10. 将X值类型设为 **"Treat X values as logarithms"**（X值视为对数值）：
    - 选择 **"No, X values are concentrations"**（否，X为浓度值），Prism将自动取对数

> ℹ️ **简单解释**：选择此选项后，Prism会对输入的浓度值自动做log₁₀变换（即0.004 → -2.40, 0.04 → -1.40, ..., 400 → 2.60），无需手动计算对数浓度，降低输入错误风险。

**初始值与迭代设置**：

11. 点击 **"Initial Values"** 标签页（初始值），通常可保持默认值，Prism会自动从数据估算
12. 点击 **"OK"** 开始运算，软件自动进行非线性最小二乘法迭代拟合

---

### 4.3.4 第四步：结果读取与IC₅₀提取

**运算完成后，Prism自动生成两个输出页面**：

**① 结果数据页（Results）**

在左侧导航栏中，找到 **"Nonlinear regression"** 下的 **"Results"** 表格，核查以下参数：

| 参数 | 含义 | 有效性标准 |
|------|------|---------|
| **LogIC₅₀** | IC₅₀的以10为底的对数值 | 应在-3至3之间（对应0.001–1000 μg/mL）|
| **IC₅₀** | 由LogIC₅₀换算的半数抑制浓度 | 最终报告数值，含95%置信区间 |
| **HillSlope** | Hill系数 / 曲线斜率 | 正常范围：0.5–2.5，若>3提示异常陡峭 |
| **R²** | 拟合优度（确定系数） | **≥ 0.95为最低要求**，< 0.95需重新评估数据 |
| **R² adjusted** | 调整后R² | 参考值，同样应≥ 0.95 |
| **95% CI (IC₅₀)** | IC₅₀的95%置信区间 | 置信区间宽度不应超过IC₅₀数值的5倍 |
| **Degrees of Freedom** | 自由度 | n（数据点数）– 2（约束后），本实验=4 |

**读取示例（24h时间点）**：

```
LogIC₅₀ = 0.5231 ± 0.0452
IC₅₀ = 3.33 μg/mL（95%CI：2.56–4.34 μg/mL）
HillSlope = 1.42
R² = 0.9876
R² adjusted = 0.9845
```

**IC₅₀最终报告形式**：

$$IC_{50, 24h} = 3.33\ \mu g/mL\ (95\%\ CI:\ 2.56 – 4.34\ \mu g/mL)$$

**② 曲线图页（Graph）**

Prism自动生成含误差棒的S形剂量-反应曲线图。检查曲线是否符合预期：
- 曲线形状应为**S形（Sigmoidal）**，从左下到右上（对于活力曲线）或右下到左上（对于抑制率曲线）
- 各数据点应**紧贴拟合曲线**，无明显偏离点
- IC₅₀点应落在**曲线中段**（约50%处），若IC₅₀超出实验浓度范围，需扩展浓度梯度

---

### 4.3.5 第五步：曲线图格式化与导出

**图表格式规范**（符合中国药学期刊投稿要求）：

**步骤1：双击曲线图进入Format Graph编辑模式**

1. 在图形界面点击 **"Change"** 选项卡中的 **"Format Graph"** 按钮（或双击图形区域进入编辑模式）

**步骤2：坐标轴设置**

2. X轴设置：
   - **标题**：输入 `log[Sappan Wood Extract] (μg/mL)`
   - **范围**：自动（由Prism根据数据自动设定，或手动设为-3至3）
   - **刻度**：对数刻度（-3, -2, -1, 0, 1, 2, 3，对应0.001, 0.01, 0.1, 1, 10, 100, 1000）

3. Y轴设置：
   - **标题**：输入 `Inhibition Rate (%)`（或 `细胞增殖抑制率 (%)`）
   - **范围**：-10至110（给上下留白，避免数据点被坐标轴截断）
   - **刻度**：0, 20, 40, 60, 80, 100

**步骤3：曲线与数据点样式**

4. 拟合曲线（Curve）：
   - 线型：**实线（Solid line）**
   - 颜色：**黑色（Black）**或深蓝色（RGB: 0, 51, 102）
   - 线宽：**1.5 pt**

5. 数据点（Data points）：
   - 标记形状：**实心圆（Filled circle，●）**
   - 大小：**6–7 pt**
   - 误差棒：**SD（Standard Deviation）**，双向（Both directions）
   - 误差棒帽宽（Cap width）：**0**（不加横帽，符合现代期刊规范）

**步骤4：IC₅₀标注线（可选，推荐）**

## 4.4 IC₅₀结果有效性判定标准

### 4.4.1 拟合质量标准（Goodness of Fit）

| 指标 | 合格标准 | 警告阈值 | 不合格标准 |
|------|--------|---------|----------|
| R²（确定系数）| ≥ 0.98 | 0.95–0.98 | < 0.95 |
| 残差分布 | 随机分布于零线两侧 | 轻微系统偏差 | 明显系统模式（U形、S形）|
| IC₅₀置信区间 | 置信区间/IC₅₀ < 2 | 2–5 | > 5（置信区间过宽）|
| HillSlope范围 | 0.8–2.0 | 0.5–0.8 或 2.0–3.0 | < 0.5 或 > 3.0 |

**不合格时的处理原则**：

1. R² < 0.95：
   - 检查是否存在未被Grubbs检验识别的异常数据点
   - 检查浓度梯度范围是否覆盖20%–80%抑制率区间
   - 若曲线在低浓度端无明显效应（抑制率<10%），考虑降低最低浓度或增加高浓度点
   - 重复实验并再次拟合

2. IC₅₀超出实验浓度范围（extrapolation）：
   - 拟合IC₅₀不在0.004–400 μg/mL范围内，提示浓度梯度设计不合理
   - 重新设计浓度梯度，确保IC₅₀在浓度范围中段

3. HillSlope异常（< 0.5 或 > 3）：
   - 提示细胞响应机制可能存在多靶点或协同效应
   - 不自动判定为无效数据，但需在结果讨论中特别说明
   - 检查是否为DMSO溶剂毒性干扰（尤其在高浓度端）

---

### 4.4.2 IC₅₀结果可报告的完整性要求

一个完整的IC₅₀报告值必须包含以下要素：

1. **数值** + **单位**：如 `3.33 μg/mL`
2. **置信区间**：`(95% CI: 2.56–4.34 μg/mL)` 或 `± 标准误差`
3. **时间点标注**：`24 h / 48 h / 72 h`
4. **独立重复次数**：`n = 3`（代表3次独立生物学重复实验）
5. **拟合R²值**：`R² = 0.988`（在方法学描述或结果表格脚注中注明）
6. **所用模型**：`四参数Logistic模型（4PL），GraphPad Prism 9.0`

**规范示例（期刊图表图注格式）**：

> 苏木乙醇提取物对CNE-2细胞的IC₅₀值：24 h = 3.33 μg/mL（95% CI: 2.56–4.34）；48 h = 1.87 μg/mL（95% CI: 1.42–2.46）；72 h = 0.94 μg/mL（95% CI: 0.71–1.25）。数据来自3次独立实验，每浓度≥5个重复孔，均值±SD，采用GraphPad Prism 9.0非线性回归（Variable slope，4PL，R²≥0.98）拟合。

## 4.5 统计学分析与报告规范

### 4.5.1 组间比较统计分析

在获得3次独立重复实验（3块96孔板，即n = 3）的IC₅₀值后，进行统计描述：

**描述性统计**：

- 均值（Mean）
- 标准差（SD）
- 标准误差（SEM = SD / √n）

**示例（三次独立实验IC₅₀汇总，24h时间点）**：

| 重复批次 | IC₅₀ (μg/mL, 24h) |
|---------|-------------------|
| Exp. 1 | 3.33 |
| Exp. 2 | 3.51 |
| Exp. 3 | 3.28 |
| **Mean ± SD** | **3.37 ± 0.12 μg/mL** |
| **Mean ± SEM** | **3.37 ± 0.07 μg/mL** |

**批次间变异系数（Batch CV）**：

$$CV_{批次间} = \frac{0.12}{3.37} \times 100\% = 3.6\%$$

批次间CV ≤ 15%为可接受范围，说明实验重复性良好。

---

### 4.5.2 多时间点比较的单因素方差分析（One-way ANOVA）

当比较24h、48h、72h三个时间点的IC₅₀均值差异时，采用**单因素方差分析（One-way ANOVA）**：

**GraphPad Prism 9.0中的操作路径**：

1. 新建 **Column数据表**（非XY图），输入三个时间点各3次重复的IC₅₀值
2. 点击 **"Analyze"** → **"Column analyses"** → **"One-way ANOVA (and nonparametric)"**
3. 参数设置：
   - 选择 **"Multiple comparisons"**: **Tukey's multiple comparison test**（Tukey事后检验）
   - 显著性水平：**α = 0.05**
   - 方差齐性检验：勾选 **"Bartlett's test for equal variances"**

4. 读取结果中的P值和多重比较结果：
   - **P < 0.05**：时间点间IC₅₀差异显著，标记为 **"*"**
   - **P < 0.01**：标记为 **"**"**
   - **P < 0.001**：标记为 **"***"**
   - **P < 0.0001**：标记为 **"****"**
   - **P ≥ 0.05**：差异不显著，标记为 **"ns"**（not significant）
