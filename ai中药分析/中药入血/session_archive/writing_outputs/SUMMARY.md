## 如何使用本论文

### 日常编辑
直接用 Microsoft Word 或 WPS Office 打开 `final/full_thesis_v2.docx`。
占位框以橙色粗体标注，填入实验数据后删除占位说明即可。

### 填写实验数据流程
1. 完成 UPLC-Q-TOF-MS 数据采集与分析
2. 在 Word 中找到对应占位框（【图3-X 待填写】标记）
3. 插入实际图表，删除占位说明文字
4. 在结论部分将【待填写】替换为实测数字
5. 更新参考文献（如有新文献）

### LaTeX 本地编译
```bash
cd drafts/
xelatex v2_draft.tex
bibtex v2_draft
xelatex v2_draft.tex
xelatex v2_draft.tex
```
需要安装 TeX Live 完整版（含 CTeX 包）。
