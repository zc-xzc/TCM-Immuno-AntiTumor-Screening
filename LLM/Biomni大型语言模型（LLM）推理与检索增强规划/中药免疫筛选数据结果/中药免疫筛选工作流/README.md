# 中药免疫激活抗肿瘤药物筛选分析

## 项目简介
本项目实现了中药免疫激活抗肿瘤药物的精准筛选分析，针对CNE1/CNE2鼻咽癌细胞系，
包含完整的数据预处理、特征工程、双效模型构建和机制推理流程。

- 结果输出: 结果输出

## 核心功能
1. **数据预处理与质控**：缺失值处理、异常值剔除、特征标准化
2. **特征工程**：构建免疫激活评分、抗肿瘤活性评分、双效综合评分
3. **双效筛选模型**：基于多维度指标的候选药物筛选
4. **机制推理**：候选药物-靶点-通路相互作用网络分析
5. **可视化输出**：相关性热图、散点图、网络图等
