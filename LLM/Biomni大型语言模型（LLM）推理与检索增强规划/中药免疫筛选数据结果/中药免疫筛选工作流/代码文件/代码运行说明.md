# 中药免疫激活抗肿瘤药物靶点机制可视化分析

## 功能说明

基于前期筛选结果，完成靶点层面的生物信息学可视化分析，生成指定图表并确保全流程数据无丢失。

## 依赖库

```
pandas==1.5.3
numpy==1.24.3
matplotlib==3.7.1
seaborn==0.12.2
networkx==2.8.8
scipy==1.10.1
```

## 运行步骤

1. 确保前期筛选结果文件存在（`中药免疫激活抗肿瘤候选药物清单.csv`）
2. 在命令行中运行以下命令：
   ```
   python 中药免疫激活抗肿瘤药物靶点机制可视化分析.py
   ```

## 参数说明

- `work_dir`：工作目录，默认为当前目录
- `seed`：随机种子，固定为42，确保结果可复现

## 输出结果

### 数据文件
- `靶点数据集质控表.csv`：靶点数据集质控结果
- `PPI网络全量数据.csv`：PPI网络节点和边信息
- `GO富集全量结果表.csv`：GO富集分析结果
- `KEGG富集全量结果表.csv`：KEGG富集分析结果
- `数据完整性验证报告.txt`：数据完整性验证结果

### 可视化文件
- `PPI网络_圆形布局.png`：圆形布局全量PPI网络
- `PPI子网络_心形布局.png`：心形布局PPI子网络
- `GO富集分析_柱状图.png`：GO富集分析柱状图
- `KEGG通路富集_气泡图.png`：KEGG通路富集气泡图

### 分析报告
- `中药免疫激活抗肿瘤药物靶点机制分析报告.html`：完整分析报告
