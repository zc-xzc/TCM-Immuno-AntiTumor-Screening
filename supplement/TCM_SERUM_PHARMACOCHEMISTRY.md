# 中药入血成分分析指南

> 基于血清药物化学（Serum Pharmacochemistry）研究框架  
> 适用于19味候选中药的体外-体内成分关联分析  
> 2026年7月

---

## 一、研究思路

中药口服后经过消化道吸收、肝脏代谢，最终起效的往往是 **入血原型成分及其代谢物**。单纯体外化学成分分析无法排除非吸收成分的假阳性干扰，因此需建立：

```
粗提物 -> 含药血清制备 -> LC-MS/MS分析 -> 入血成分鉴定
  |                              |
  v                              v
体外活性跟踪                        体内-体外成分-活性关联
```

## 三、关键步骤详解

### 3.1 含药血清制备

| 参数 | 推荐方案 | 可选方案 |
|------|---------|---------|
| 动物 | SD大鼠 (200-250g) | BALB/c小鼠 |
| 给药途径 | 灌胃 (i.g.) | 腹腔注射 (i.p.) |
| 给药周期 | 7天, bid | 单次给药 |
| 采血时间 | 末次后0.5h, 1h, 2h | 多点时间曲线 |
| 血清处理 | 56度 30min 灭活 | 不灭活 |
| 保存 | -80度, 避免反复冻融 | -20度短期 |

### 3.2 LC-MS 分析参数推荐

| 参数 | 推荐值 | 说明 |
|------|-------|------|
| 色谱柱 | C18 (2.1x100mm, 1.8mm) | 通用反相 |
| 流动相 | A: 0.1%甲酸水 B: 乙腈+0.1%甲酸 | 正离子模式 |
| 梯度 | 5-95% B, 30min | 通用梯度 |
| 流速 | 0.3 mL/min |  |
| 柱温 | 40度 |  |
| 质谱 | ESI-QTOF MS/MS | 正负离子均采集 |
| 扫描范围 | m/z 100-1500 | 覆盖小分子 |
| MS/MS能量 | 10-40 eV (梯度) | 碎片信息丰富 |

### 3.3 数据处理流程

**步骤1：峰发现与对齐**
```
推荐软件：
- Progenesis QI (商业, Waters)
- MZmine 2/3 (免费开源)
- XCMS Online (免费在线)
- MS-DIAL (免费, RIKEN)

参数：
- 质量偏差: <5 ppm
- 保留时间窗口: 0.1-0.2 min
- 最小强度: 1000 counts
- 信噪比: >10
```

**步骤2：代谢物鉴定策略**

| 优先级 | 策略 | 工具 | 置信度 |
|--------|------|------|--------|
| 1 | MS/MS匹配标准品 | 自建库 | 确认 |
| 2 | MS/MS匹配公共数据库 | GNPS/METLIN | 高置信度 |
| 3 | MS/MS谱匹配in silico碎裂 | SIRIUS+CSI:FingerID | 中置信度 |
| 4 | 精确质量+保留时间预测 | 数据库查询 | 推测 |

**关键数据库**：
- **UNIFI** (Waters)：中药天然产物库
- **GNPS** (https://gnps.ucsd.edu/)：分子网络
- **METLIN** (https://metlin.scripps.edu/)：代谢物标准谱
- **MoNA** (https://mona.fiehnlab.ucdavis.edu/)：质谱库
- **TCM-DCABM**: 中药入血成分库

## 五、常见问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 血清基质干扰严重 | 内源性物质丰富 | SPE固相萃取；UHPLC分离延长；SWATH采集 |
| 入血浓度过低 | 生物利用度差 | 增加给药剂量；富集/提高给药频次 |
| 代谢物鉴定困难 | 缺乏标准品 | GNPS分子网络组注释；体内代谢预测（GLORYx, BioTransformer） |
| 血清活性差 | 活性成分浓度不足 | 体外实验浓度换算；直接使用代谢物组 |
